# gibberish.zsh

Simple keyboard layout autocorrection for Zsh.

![Preview](assets/preview.gif)

## Installation

[Zplug](https://github.com/zplug/zplug):

```sh
zplug "lnkrr/gibberish.zsh"
```

[Zinit](https://github.com/zdharma-continuum/zinit):

```sh
zinit light lnkrr/gibberish.zsh
```

## Options

```sh
# specify layout:
GIBBERISH_FROM="qwerty"
GIBBERISH_TO="ycuken" # or GIBBERISH_TO="йцукен"

# or manually:
# GIBBERISH_MAP_FROM="..."
# GIBBERISH_MAP_TO="..."

# load the plugin after settings the options
```
